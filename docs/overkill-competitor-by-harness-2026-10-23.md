# Per-harness Overkill feature comparison

October 23, 2026. Research only. [Read the prioritized overview and canonical contracts](overkill-competitor-parity-2026-10-23.md). [CSV](overkill-competitor-parity-2026-10-23.csv) and [source/search evidence](overkill-competitor-parity-2026-10-23.json) retain full metadata.

These are overlapping selected reference patterns, not a vendor feature tally, percentage parity score, tested quality ranking or exhaustive enumeration of flags/endpoints. Optional, extension and experimental capabilities must be interpreted under each section's upstream boundary. A Have rating refers only to the narrow feature name and stated scope. Per-product overrides retain differences when the generic primitive is insufficient.

## Hermes Agent

A persistent assistant reachable from multiple channels, with learning as an explicit workflow. [Skills](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills), [Telegram team guide](https://hermes-agent.nousresearch.com/docs/guides/team-telegram-assistant). Public Python source is downloaded.

The comparison does not assume all referenced capabilities are loaded in every session. Framework/plugin/preview and client restrictions from the source landscape apply.

| ID | Selected feature | Overkill | Priority | What we have / what remains |
|---|---|---|---|---|
| F01 | Read/search/list workspace files | **Have** | P0 | Registered filesystem and grep tools operate in the selected workspace; this does not confine arbitrary shell effects. |
| F02 | Patch/write real files | **Have** | P0 | Filesystem and patch tools are registered and actual file effects have controlled-provider acceptance. |
| F03 | Bounded shell execution and cancellation | **Have** | P0 | Registered shell has bounded output and owned-process cancellation; a command invocation is not a persistent interactive session. |
| F07 | Real browser navigation/forms/screenshots | **Partial** | P0 | Registered chromedp and developer-browser tools exist; external Chrome/backend requirements, default restricted-mode refusal and app UX differ from a ready embedded browser. |
| F11 | Web fetch and search | **Have** | P1 | A web tool is registered; supported providers and configured credentials still determine availability. |
| F13 | Images, generated media and voice primitives | **Partial** | P2 | Image/vision, image-generation and TTS tools are configured/registered; that is not a seamless voice-input/computer-use or office-authoring product. |
| F16 | Hierarchical repository instructions | **Have** | P1 | Shared CLI/API runtime and children construct scoped instruction sources; bounded supported discovery is not every vendor precedence rule. |
| F19 | Durable compaction and retained raw history | **Have** | P0 | PostgreSQL-backed Seahorse DAG compaction is now wired into shared agents with real search/describe/expand tools; historical unwired findings are superseded. |

Selected source-specific boundaries:

- Profile/toolset/credentials/container/backend and platform gates apply; memory, skills, goals, Kanban and child delegation differ.
- Hermes agent-created skills are a broader learning reference; Overkill Have is limited to its explicit reviewed workflow, not unattended parity.
