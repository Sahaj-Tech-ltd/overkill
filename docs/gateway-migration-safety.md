# Gateway store startup safety

Bookmarks, input history and message-delivery stores now run migrations in bounded PostgreSQL transactions under schema-specific owner advisory locks. Central bootstrap uses the same bookmark/history definitions and locks. Concurrent updated entry points therefore serialize table/index creation, and a failure rolls back every statement in its participating transaction. Constructors use a ten-second context and return no store on failure, including a missing pool. Store constructors remain separate transactions; this does not create a transaction across all application startup.

Real PostgreSQL regressions reproduced two failures before the repair: a JSON bookmark label made the late label index fail after the session index had already committed; twenty-four concurrent central/store constructors could collide on PostgreSQL's table type uniqueness constraint. The repaired tests verify rollback, retained malformed data, explicit operator repair followed by two successful startups, and fresh mixed startup followed by actual bookmark/history/delivery writes and reconstruction.

Held-lock tests independently cover all three owner keys. A caller deadline ends migration without a created table; releasing the lock allows retry. Missing database pools return errors. The focused gateway/central/shared-schema suite passes (`.cache/gateway-migration-focused.log`), followed by ten repetitions of the new failure, concurrency, nil-pool and held-lock cases (`.cache/gateway-migration-repeat.log`). The pre-fix failures are retained in `.cache/gateway-migration-before.log`.

SQL definitions are in `internal/dbschema/gateway.go`. Central bootstrap acquires its shared owner locks in a fixed order before any DDL. Standalone gateway stores acquire one owner lock, so they never invert that order. An older binary or manual DDL does not participate in these advisory locks. This repair does not validate every incompatible historical schema, same-name index definition, live messaging provider, or database crash/major-version upgrade. Original VALIDATE-01 remains broader than these cases.
